
# Log Data Processing & Monitoring Pipeline

## Overview
This project simulates a real-world log processing pipeline used for monitoring system health and analyzing errors.

## Features
- Log data ingestion and processing
- Error filtering and analysis
- Service-level monitoring
- Data visualization (bar chart, pie chart, trend analysis)

## Tech Stack
- Python
- Pandas
- Matplotlib

## Project Files
- logs.csv → Raw log data
- error_logs.csv → Processed error logs
- log_data_pipeline.ipynb → Data processing and analysis notebook

## Key Insights
- Total error count
- Service-wise error distribution
- Log level distribution
- Daily error trends

## Use Case
This project demonstrates how log data can be processed to monitor system performance and identify failures, similar to real-world monitoring systems.
